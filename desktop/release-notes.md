## Opravy

- **Overlay za hrou:** když se Overwatch spustil až po Counterpick Atlasu, první overlay po <kbd>Alt+C</kbd> zůstal schovaný za oknem hry. Teď se ukáže navrchu pokaždé a hra si přitom nechá myš.

Stáhni si jen jeden soubor: **Setup** je instalátor, **portable** se spouští bez instalace. Aplikace není podepsaná, takže Windows napoprvé ukážou varování: *Další informace → Přesto spustit*.

## Fixes

- **Overlay behind the game:** when Overwatch was started after Counterpick Atlas, the first overlay after <kbd>Alt+C</kbd> stayed hidden behind the game window. It now always shows on top, and the game keeps the mouse.

Download one file only: **Setup** installs the app, **portable** runs without installing. The app isn't signed, so Windows shows a warning the first time: *More info → Run anyway*.
