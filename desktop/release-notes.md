## Opravy

- **Rozpoznávání na novém scoreboardu:** overlay teď spolehlivě najde rámečky hrdinů i v nejnovější verzi hry (kroužky úrovně u portrétů, zelený proužek u hráčů z party). Dřív se mu tam řádky posouvaly, scoreboard občas nenašel vůbec nebo místo 5 řádků četl 6. Nevadí mu ani banner „Endorsement received“ nebo chat přes okraj tabulky. Na třech nových screenshotech ze hry trefil 28 hrdinů z 30, zbylé dva označil otazníkem.
- **Ikony rolí:** čte i menší ikony rolí nového scoreboardu, takže řádek DPS už nepovažuje za tanka.
- **Vzorky:** přibyly vzorky ze 3 nových scoreboardů (43 hrdinů celkem, nově třeba Freja, Doctrine, Domina, Ramattra a Venture). Aplikace si je stáhne sama.
- **Karta „Tvůj hrdina“:** text „neutrální volba“ se už neláme po jednom slově.

Stáhni si jen jeden soubor: **Setup** je instalátor, **portable** se spouští bez instalace. Aplikace není podepsaná, takže Windows napoprvé ukážou varování: *Další informace → Přesto spustit*.

## Fixes

- **Recognition on the new scoreboard:** the overlay now reliably finds the hero portraits in the latest game version (level rings next to the portraits, a green strip for party members). Before, its rows drifted off, it sometimes missed the scoreboard altogether or read 6 rows instead of 5. An "Endorsement received" banner or the chat over the edge of the table no longer gets in the way. On three new in-game screenshots it got 28 of 30 heroes right and marked the other two with a question mark.
- **Role icons:** it reads the smaller role icons of the new scoreboard, so a damage row is no longer taken for a tank.
- **Samples:** samples from 3 new scoreboards were added (43 heroes in total, now including Freja, Doctrine, Domina, Ramattra and Venture). The app downloads them by itself.
- **"Your hero" card:** the "neutral pick" text no longer wraps one word per line.

Download one file only: **Setup** installs the app, **portable** runs without installing. The app isn't signed, so Windows shows a warning the first time: *More info → Run anyway*.
